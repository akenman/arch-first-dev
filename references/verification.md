## 契约修复优先序与三要件【已验证】

跨模块数据/行为不一致时（eval 实测多轮）：

```
默认：在数据属主（生产者）的读写边界单点规范化，让所有消费方自动对齐。
  属主边界是唯一能看到"全部写法"的位置；在此收口后，存量数据和新增数据
  同时被规范化，契约有了唯一落实点（写入 BEHAVIOR 声明并 @see 蓝图）。
例外：消费方就地修补仅允许作为 hotfix，条件是受影响文件 ≤ 2，且必须
  记 @DECISION 说明收敛计划。
三要件（正确的修复若不留痕，审查者无法与运气区分）：
  修复质量 = ① 在数据属主边界收口（或说明属主不可行的理由）
           + ② 消费方零改动或改动有契约依据
           + ③ @DECISION 的「替代方案考虑过」明确点名被否决的另一条路径
反面教材（eval 实测）：在统计函数比较处就地 replace('/', '-') 修复，
  能通过全部功能性验证，但混格式数据继续落盘、无契约记录——"能跑但逻辑会继续烂"。
```

## 蓝图健康度自诊【已验证-结构部分】【未验证-语义部分】

结构分由 scripts/validate_blueprint.py 确定性计算（可复现、零遗漏），模型只评估
语义类检查项。不要让模型心算扣分——同一蓝图两次评分不同就说明评分不可信。

```
结构分（脚本）: @MODULE 字段完整每缺 -1 | @BUILD_ORDER 逆依赖 -10 | 幽灵依赖 -5/个
              | 循环依赖 -10 | 消费者覆盖缺失 -2/个 | 状态不一致 -2/个
语义分（模型）: 契约完备性 30 分（四段声明缺失 -2/项；边界矩阵未填 -3/模块；
              错误链缺失 -5/条）| 变更可控性 25 分（@CHANGE 缺失 -3/次；
              @DECISION 缺失 -5/个；未解决 rollback -5/个）
阈值: ≥90 🟢 | 70-89 🟡 建议修复 | <70 🔴 必须修复
```

## 蓝图漂移检测【已验证-机制】

蓝图是快照，代码是活的。三层检测，从快到慢：

**第 1 层 — 签名快照比对（1 秒）**

Phase 3 完成时，由 `python scripts/validate_blueprint.py .arch/BLUEPRINT.md --signatures`
生成 `.arch/SIGNATURES.json`（含 @EXTERNAL 契约文件 sha256，每次迭代完成后重新生成）。
迭代模式启动时读取当前代码签名比对：签名变化 → 🟡；新增 → 🟢 扩展；删除 → 🔴 收缩。
CI 可用 `--check-signatures` 门禁（模板 templates/ci-blueprint.yml）。

**第 2 层 — 依赖关系比对（5 秒）**：重扫 import 与蓝图依赖字段比对；
违反模块边界 → 🔴 约束 5 违规。

**第 3 层 — BEHAVIOR 抽样验证（30 秒，仅完整模式）**：抽 3 个接口跑契约测试。

自动修复规则：🟢 扩展类漂移自动追加蓝图 + @CHANGE；🟡/🔴 提示用户确认，不自动修改。

## Phase 3 失败恢复细则【已验证】

```
①❌ 流验证失败 → 缺失模块/接口标 [empty]，回 Phase 2
②❌ 依赖检查失败 → 蓝图错改蓝图记 @CHANGE；代码错改代码重新对照 BEHAVIOR
③❌ 边界检查失败 → 补边界处理代码，更新边界矩阵
④❌ 错误链检查失败 → 补传播路径，更新 @ERROR_CHAIN
⑤❌ 空位检查失败 → 回 Phase 2 继续填充
⑥❌ 变更回溯失败 → 逐条检查 @CHANGE 确认已整合
⑦❌ 运行时验证失败 → ImportError 查路径/导出；运行时异常查 pre 落实；
   输出不符查 post 落实；UI 白屏查导入链与渲染入口
⑧❌ 摘要失败 → 不阻塞可跳过
原则: ①②⑤ 必须修复后重验；③④⑦ 定点重验；⑥ 逐条修复；⑧⑨ 可跳过
```

## 契约测试进阶（差异测试 + 属性测试）【未验证】

两个从未被 eval 触达的测试升级，设计保留、使用前自行验证：

**差异测试**——验证"代码是否偏离蓝图"（即使能跑，行为与声明不一致就是 bug）：
从 BEHAVIOR 声明生成契约测试（pre → 违反时抛声明错误；post → 返回值满足声明；
side-effect → 状态变化如声明），运行后出差异报告，失败项 Phase 3 完成前必须修复。

**属性测试**——BEHAVIOR 声明天然是属性，可自动推导随机测试：
```
pre  → 反向属性: name 非空 → 生成 ["", null, "  "] 断言 raises(声明的 error)
post → 正向属性: id 自增唯一 → 随机输入 200 个断言严格递增
side-effect → 状态属性: _data 追加一条 → len 前后差 = 1
error → 触发属性: 空标题 → raises(ValueError) 且非 TypeError
框架: Python Hypothesis / TS fast-check / Go testing/quick / Rust proptest
价值: 发现"声明本身有漏洞"（如并发场景下 post 不成立）——前两者的补集
```

两者与逐行对照互补：对照发现"声明没有对应代码"，差异测试发现"行为与声明不符"，
属性测试发现"声明本身有漏洞"。自动生成规则：简化模式只为跨模块接口生成；
完整模式全量 + 报告。骨架测试桩由 scripts/scaffold.py 生成（skip 桩）。
